  - id: the-interesting-cases
    heading: The cases that actually found bugs
    paragraphs:
      - Push-before-pull, so the server can never discard an edit that had simply not uploaded yet. Deletes tombstoned rather than dropped. Voucher counters merged by maximum, because skipping a number is harmless and repeating one is not.
      - The sync-hardening work is the honest story here — a cycle used to send every table together, so one table refused by a policy stranded the whole queue behind it. Say what that looked like and what it cost before it was found.
